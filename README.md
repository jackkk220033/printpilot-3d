# JJ3D v4.11.17 — Impression des bons d’envoi corrigée

Le bon d’envoi est désormais généré directement par le module Factures. Il ne dépend plus du chargement de `bon-boutique.html`, qui restait bloqué dans certains navigateurs.

**Utilisation :** Factures → Bon d’envoi → PDF / Imprimer → Imprimer ou Enregistrer en PDF. Les boutons Supprimer avec confirmation pour factures et bons d’envoi de v4.11.16 sont conservés.

Les bons d’envoi ne modifient pas automatiquement les quantités en stock.
