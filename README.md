# PrintPilot 3D v4.10.1 – Menu réorganisé

Basé sur la v4.10. Réorganisation uniquement de la navigation : Atelier / Boutique / Outils & statistiques. Le menu gauche reste fixe avec une zone défilante, les rubriques sont repliables, et le menu Plus du téléphone est regroupé. Ouverture automatique de la rubrique contenant la page active. Les compteurs de Demandes Boutique et Messages Boutique restent attachés à leur propre lien.

## Installer
1. Sauvegarder les données JSON depuis PrintPilot.
2. Remplacer `index.html` et `css/style.css` depuis ce ZIP sur GitHub (le ZIP contient aussi le reste de la v4.10 inchangé pour installation complète).
3. Attendre le succès de GitHub Pages, puis recharger avec Ctrl+Shift+R.
4. Vérifier le titre `PrintPilot 3D v4.10.1`, les rubriques Atelier/Boutique/Outils, le badge Demandes et Messages.

Aucun changement Firebase ni règles Firestore n'est requis. Les pages, actions et données restent inchangées.
