# JJ3D v4.11.11 — Informations commandes

Version complète basée sur JJ3D v4.11.10. Icône PWA, nom, code et configuration Firebase conservés.

## Modifications
- Informations clients dans le Catalogue et la section Commander du portail Boutique.
- Note discrète dans la fiche détaillée des produits de la Boutique.
- Rappel dans Catalogue à partager (administration) et dans le catalogue HTML exporté.
- Couleurs habituelles : noir, blanc, bleu, rouge et vert. Autres couleurs sur demande, supplément éventuel communiqué avant la production.
- Frais d'expédition à la charge du client, communiqués selon destination/colis.
- Préparation / fabrication : environ deux semaines; le délai du transport s'ajoute.

**Aucun calcul de frais, aucune modification des prix ou données Firebase, aucun changement aux règles de sécurité.** Les commandes Boutique demeurent des demandes de production à confirmer.

## Déploiement
Publier tous les fichiers du dossier sur Firebase Hosting comme avant. La PWA installée prendra la nouvelle version après actualisation.
